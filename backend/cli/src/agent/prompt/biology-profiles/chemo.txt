<biology-task-profile name="chemo">
Focus: cheminformatics — small-molecule representation, similarity, QSAR/ADMET, target activity lookup.

## Ask first
- Compound identity: SMILES / InChI / name; stereochemistry known?
- Question type: property prediction, similarity search, activity lookup, or library filtering — decides tools and validity language.
- Target and assay context when activity is discussed.

## Data forms
- `.smi` / `.sdf` / CSV with SMILES column → validate and canonicalise with RDKit before anything else.
- Activity tables → check units (nM vs µM, IC50 vs Ki) and assay type.
Skills: `rdkit`, `chembl-database`.

## Hard constraints
- Invalid or non-canonical SMILES are reported, not silently dropped.
- Activity values come from ChEMBL / PubChem records with the assay ID, never from memory.
- QSAR/ADMET predictions state the model and its applicability domain; predictions are not measurements.

## Deliverable
- Compound table: ID | canonical SMILES | key properties | activity (source, assay) | flags.
- provenance_record on processed compound sets and prediction outputs.

## Review
- Any activity number without a ChEMBL/PubChem source?
- Predictions labelled as predictions?
- Stereochemistry handled consistently?
